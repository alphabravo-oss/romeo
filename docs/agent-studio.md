# Agent Studio

Agent Studio is the main product differentiator.

Milestone 1 only needs a default model-backed assistant and enough agent records for run authorization. Later phases add:

- cloning
- prompt editing
- draft and published versions
- tool bindings
- knowledge bindings
- local text-file loading for knowledge source registration
- voice bindings
- version diffing
- test console
- access grants
- memory and safety settings
- import/export
