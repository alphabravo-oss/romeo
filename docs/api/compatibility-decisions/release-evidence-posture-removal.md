# Release-evidence posture fields are removed

Romeo previously read operator-mounted "GA evidence" and "live evidence" JSON
files (generated by release tooling that no longer exists) and echoed sanitized
summaries of them through admin posture endpoints. The tooling was retired, so
the product no longer reads those files and the corresponding `*_EVIDENCE_PATH`
and GA/release/CI path environment variables are gone.

Removed from the API:

- `GET /api/v1/admin/ga/evidence-posture` (`operationalPosture.getGaEvidence`)
  and its `GaEvidencePostureReport` schemas.
- `liveEvidence` and evidence-related `redaction` flags from
  `edgeSecurity.getPosture` and `browserAutomation.getPosture`, plus
  `deployment.liveEvidencePathConfigured` from the browser-automation posture.
- `queryPlanReview`, `slowQueryTelemetry`, `lockTelemetry`,
  `archivalPartitioning`, and evidence-related `redaction` flags from
  `operationalPosture.getPostgres`.
- `vector.externalStore.evidence`, `vector.physicalIsolation.evidence`, and
  `vector.physicalIsolation.externalVectorEvidence` from
  `ragGovernance.getPosture`; physical isolation now reports `satisfied` when
  the deployment matches the policy.
- `retentionEvidence` from `governance.getDataRightsCoverage`.

All remaining posture fields describe live runtime configuration. Clients that
read the removed fields should drop them; there is no replacement because the
evidence files they summarized are no longer produced. The product has not had
a public release, so these removals are made without a deprecation window and
are retired at the 2.0 contract boundary.
