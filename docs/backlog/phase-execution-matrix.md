# Phase Execution Matrix

This matrix is the backlog control surface for the remaining PRD work. Strategy and scope live in the linked track files. Concrete execution tickets with task details, definitions of done, tests, validation, Compose/Kubernetes impact, and security/migration notes live in [Remaining Work Execution Backlog](./execution/README.md) so no single backlog file becomes a maintenance problem.

## Status Labels

- `In progress`: implementation exists but evidence gates are not complete.
- `Ready next`: prerequisites are clear and work can start after the listed dependency.
- `Blocked`: a required upstream phase or decision is missing.
- `Conditional`: required for full product completeness, but may be deferred from a narrower deployment only with an explicit exception.

## Required Evidence Artifacts

- Schema validation output after migration and after restore.
- Repository conformance report for in-memory and Postgres, including strict method coverage and failure-injection evidence where Phase 19 requires atomic behavior.
- Compose clean-start, restart-persistence, backup, and restore logs with secrets redacted.
- Helm render/lint output for external Postgres, CloudNativePG, explicit NetworkPolicy egress values, CloudNativePG operator-example validation, and optional KEDA ScaledJob example validation.
- Kubernetes live-smoke output, readiness report, pod/job log redaction scan, and restricted-pod posture review.
- Release artifact manifest with image digests, package versions, SBOM, scan evidence, and readback.
- Security review notes for connector egress, worker secret access, audit metadata, usage metadata, jobs, and webhook payloads.
- Load, soak, query-plan, and failure-drill evidence for the selected deployment tier.
- Final GA checklist with explicit exceptions for any conditional phase not shipped in a given deployment.
