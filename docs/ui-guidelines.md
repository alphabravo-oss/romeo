# UI Guidelines

Romeo should feel clean, fast, and operational rather than decorative.

Rules:

- first screen is the usable workspace, not a landing page
- navigation is predictable and dense enough for repeated use
- buttons use icons where symbols are familiar
- cards are for repeated items and tool panels, not nested section decoration
- dark and light themes must both be complete
- long chat/message lists must be virtualized or use content visibility
- admin screens use tables, filters, and explicit empty states
